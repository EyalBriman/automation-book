# ספר תרגילים באוטומציה ומערכות משולבות

זהו אתר GitHub Pages לספר התרגילים בעברית.

## מה כלול באתר

- פרק 1: מודלים ובקרה.
- פרק 2: שאלות הלוגיקה 2.1.1 ו־2.1.2, כולל הפתרונות וטבלאות קרנו הצבעוניות.
- פרק 3: שלד בהתאם למסמך המקור.
- פרק 4: חיישנים ומפעילים, סעיפים 4.1–4.7.
- פרק 5: חמש שאלות בחינה מרובות סעיפים.
- בכל שאלה מרובת סעיפים, הפתרון של כל סעיף נפתח בנפרד.

חומר בחינה שטרם פורסם אינו נכלל באתר או בארכיון הציבורי.

## תהליך הבנייה

```text
Word פרטי
├── Pandoc → טקסט, נוסחאות, טבלאות ותמונות רגילות
└── LibreOffice + PyMuPDF → שרטוטים, מחברים וקבוצות צורות
                         ↓
                 GitHub Pages
```

הטקסט נשאר HTML סמנטי ובר־בחירה. נוסחאות, קוד וסימונים באנגלית מבודדים משמאל לימין בתוך העמוד העברי.

## תמונות ודיאגרמות

דיאגרמות הבנויות מ־Word Shapes, מחברים או צורות מעל טבלאות מרונדרות אוטומטית כתמונה אחת ונחתכות לפי גבולות התוכן. אין שימוש בקואורדינטות חיתוך ידניות.

## מבנה הפרויקט הציבורי

```text
docs/                              האתר המוכן לפרסום
scripts/build-from-word-pandoc.py  בנייה מקומית ממקור Word פרטי
scripts/validate-book.py           בדיקות שלמות ואבטחת פרסום
```

קובץ ה־Word הפרטי אינו כלול במאגר הציבורי. כך חומר שאינו מיועד לפרסום אינו ניתן להורדה דרך GitHub.

## בנייה מקומית ממקור פרטי

דרושים Python 3.10 ומעלה, Pandoc ו־LibreOffice Writer.

```bash
python -m pip install -r requirements.txt
python scripts/build-from-word-pandoc.py /path/to/private-updated-book.docx --out docs
python scripts/validate-book.py --docs docs
```

## GitHub Pages

ה־workflow מאמת ומפרסם את תיקיית `docs/` שכבר נבנתה. הוא אינו זקוק לקובץ ה־Word הפרטי.
