# ספר תרגילים באוטומציה ומערכות משולבות

זהו פרויקט GitHub Pages לספר התרגילים בעברית.

הגרסה הזו משתמשת בגישה הבאה:

```text
Word (.docx) → Pandoc semantic HTML → GitHub Pages
```

כלומר, האתר אינו מבוסס על LaTeX ואינו מבוסס על חיתוך תמונות של עמודים.  
קובץ ה־Word הוא מקור התוכן, ו־Pandoc משמש לקריאת הטקסט, התמונות, הטבלאות והנוסחאות.

## מה כלול באתר כרגע

- כל פרק 1: **מודלים ובקרה**
- שתי שאלות מפרק 2: **2.1.1 בקר השקייה** ו־**2.1.2 בקר למקרר תעשייתי**
- שלד ליתר הפרקים
- פתרונות מוסתרים שנפתחים בלחיצה על **הצג פתרון**

## מבנה הפרויקט

```text
source/Automation_book22June2026.docx   מקור התוכן
source/assets/                         תיקוני תמונה ידניים למקרים שבהם Word/Pandoc מפרק דיאגרמה
scripts/build-from-word-pandoc.py       בניית האתר מתוך Word בעזרת Pandoc
docs/                                   האתר ש־GitHub Pages מציג
```

## הערה על דיאגרמות Word

רוב התמונות מגיעות ישירות מקובץ ה־Word דרך Pandoc. במקרה אחד, **1.7.1 סעיף ד**, הדיאגרמה המקורית ב־Word מתפרקת לקטעי טקסט במקום לתמונה תקינה. לכן הדיאגרמה נשמרת כקובץ תמונה ידני ב־`source/assets/1-7-1d-closed-loop.png`, וה־build משלב אותה אוטומטית באתר.

## בנייה מקומית

צריך להתקין Pandoc ו־Python.

```powershell
pip install -r requirements.txt
python scripts\build-from-word-pandoc.py source\Automation_book22June2026.docx --out docs
```

אחר כך פותחים:

```text
docs/index.html
```

## GitHub Pages

ה־workflow ב־GitHub Actions מתקין Pandoc, בונה מחדש את האתר מתוך קובץ ה־Word, ואז מפרסם את תיקיית `docs/`.



הערה: בגרסה זו תמונת הפתרון של 1.1.3 מוחלפת בתמונה מתוקנת כדי למנוע פירוק של שרטוטי Word בזמן ההמרה לאתר.


## תיקון RTL/LTR

בגרסה זו תוקנו מופעים שבהם סימונים מתמטיים בתוך עברית, למשל `M_1`, `t=3` ו־`t→∞`, נשמרים כיחידות משמאל לימין בתוך הטקסט מימין לשמאל.
